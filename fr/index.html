Questions fréquentes

Où est stocké le journal de bébé ?

Uniquement sur votre téléphone, dans l'app. Il n'y a pas de compte, et nous ne recevons ni le journal, ni le profil de bébé, ni sa photo.

Mes données seront-elles transférées sur un nouveau téléphone ?

Oui, au sein d'une même plateforme. iPhone : configurez le nouvel iPhone à partir d'une sauvegarde iCloud ou d'une sauvegarde sur Mac ou PC, ou transférez les données directement depuis l'ancien iPhone ; le journal fait partie de la sauvegarde de votre iPhone. Android : activez la sauvegarde Google, ou copiez les données de l'ancien téléphone lors de la configuration du nouveau ; le journal, le profil et les réglages seront restaurés. Il n'est pas encore possible de transférer le journal entre iPhone et Android.

Peut-on tenir le même journal à deux ?

Pas encore : le journal est stocké sur un seul téléphone et ne se synchronise pas entre appareils. Si c'est important pour vous, dites-le-nous.

Comment ajouter un widget ?

iPhone : maintenez le doigt sur une zone vide de l'écran d'accueil, touchez Modifier → Ajouter un widget, puis cherchez NomNom. Android : maintenez le doigt sur une zone vide de l'écran d'accueil, touchez Widgets, trouvez NomNom et faites glisser un widget sur l'écran d'accueil. Dans l'app, la roue dentée de l'onglet Accueil → Widgets montre ce que fait chaque widget et, sur la plupart des téléphones Android, permet de l'ajouter directement.

Les rappels n'arrivent pas : que vérifier ?

Vérifiez que les notifications de NomNom sont autorisées : sur iPhone dans Réglages → Notifications → NomNom, sur Android dans Paramètres → Applications → NomNom → Notifications. Vérifiez aussi que les rappels voulus sont activés dans l'app (roue dentée de l'onglet Accueil → Notifications). Certains rappels n'arrivent que s'il y a une raison, par exemple le rappel de répéter un allergène, deux jours après un essai.

Comment supprimer toutes mes données ?

Supprimez l'app de votre téléphone : le journal, le profil et la photo sont supprimés avec elle. Des copies peuvent subsister dans des sauvegardes faites auparavant : dans iCloud ou sur un ordinateur pour l'iPhone, dans votre compte Google pour Android.

NomNom remplace-t-il le pédiatre ?

Non. L'app donne des informations générales sur la diversification alimentaire. Pour toute question sur la santé de bébé ou les allergies, parlez-en à votre pédiatre.
